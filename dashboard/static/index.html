How to read this desk

This is paper money only. Each sync recomputes walk-forward HistGradientBoosting probability that TQQQ rises over the next ~5 days. If p(up) ≥ 55% the signal is LONG; otherwise FLAT. The paper book then buys, sells, hits a stop, or holds. The decision log keeps every comparison so you can see the percentage and what happened. Syncs run weekdays around open, hourly in RTH, after close, or via Run sync.
