How to read this desk

This is paper money only. The model is a walk-forward HistGradientBoosting classifier on daily TQQQ features (returns, volatility, SMA distance, RSI, ATR, volume, Donchian, plus SPY/QQQ/VIX). It goes long when predicted probability ≥ 0.55, with an 8% hard stop and 12% trailing stop. The server resyncs on weekdays after the US cash close (21:15 UTC) and whenever you hit Run sync.
